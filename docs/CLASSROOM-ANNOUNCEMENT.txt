【9/14（一）論文轉簡報課程：請先完成課前準備】

請帶自己的筆電與充電器，使用自己的 ChatGPT 帳號。請於 9/13（日）晚間前完成以下事項；卡住也請回報，不必等全部成功。

1. 下載老師提供的完整 classroom 教材 ZIP，全部解壓縮。不要另外下載整合版，也不要在 ZIP 視窗內執行。
2. 用瀏覽器開啟 docs/CLASSROOM-STUDENT-GUIDE.html，依 Mac / Windows 路線完成安裝。
3. Mac 雙擊 check-classroom-macos.command；Windows 雙擊 check-classroom-windows.cmd。
4. 在 Codex 選擇同一個教材根目錄，貼上指南的「只讀驗證提示詞」。先不要花額度生成整份簡報。
5. 回覆以下文字：

作業系統 / 處理器：
教材版：2026.09.14-r1
doctor：通過 / 未通過
smoke-test：通過 / 未通過
Codex 讀取 skill：成功 / 尚未成功
Codex 執行本機 doctor：成功 / 尚未成功
PDF 匯出工具：已安裝 / 尚未安裝
需要協助：無 / 安裝 / 帳號 / 權限 / 其他

免費帳號可以先測試，不要求先購買訂閱，也不需要申請 API key。完整 40–55 張簡報是否能完成，仍受個人額度影響。

請勿傳密碼、驗證碼、API key 或完整個人路徑。錯誤畫面請遮住姓名及路徑；學校或醫院管制電腦請洽資訊人員，不要關閉防毒或繞過管理政策。

安裝卡住的同學仍可上課，將安排與已準備完成的同學共看操作，不共用帳號或密碼。
